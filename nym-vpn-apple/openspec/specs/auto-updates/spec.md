# Auto-Updates Specification

> Generated by openlore on 2026-06-26
> Source files: `ServicesMacOS/Sources/AutoUpdater/AutoUpdater.swift`, `AutoUpdates/Sources/{CheckForUpdatesViewModel,CheckForUpdatesView}.swift`, `NymVPNDaemon/NymVPNDaemonApp.swift`, `Installer/Scripts/{preinstall,postinstall}`

## Purpose

Manages Sparkle-based auto-update checking and installation on macOS via the Sparkle updater controller, provides a manual "check for updates" UI, and coordinates privileged-daemon shutdown/install around app relaunch through installer scripts.

## Requirements

### Requirement: Sparkle Updater Initialization

The system SHALL lazily initialize the Sparkle standard updater controller with the updater started and a delegate attached.

#### Scenario: Start updater on launch
- **GIVEN** the app initializes the auto-updater
- **WHEN** the Sparkle updater controller is created
- **THEN** the updater starts and is exposed for update checks

### Requirement: Manual Update Check

The system SHALL bind a UI control to the updater's can-check state and trigger an update check on user action.

#### Scenario: User checks for updates
- **GIVEN** the updater reports it can check for updates
- **WHEN** the user taps the check-for-updates control
- **THEN** a Sparkle update check is triggered

### Requirement: Pre-Update Daemon Shutdown

The installer SHALL gracefully shut down and unregister the running daemon before installing the new package.

#### Scenario: Prepare daemon for restart
- **GIVEN** a new package installation begins
- **WHEN** the preinstall script runs
- **THEN** the daemon is prepared for restart and the old service registration is removed

### Requirement: Post-Update Daemon Installation

The installer SHALL register and enable the privileged helper daemon under the new app binary tree after installation.

#### Scenario: Install service after update
- **GIVEN** the package installs successfully
- **WHEN** the postinstall script runs
- **THEN** the daemon service is registered under the new app binary

### Requirement: Relaunch Preparation

The system SHALL prepare for relaunch when Sparkle is about to relaunch the app, restoring a visible activation policy and coordinating shutdown.

#### Scenario: Prepare to relaunch
- **GIVEN** Sparkle is about to relaunch the app after installing an update
- **WHEN** the will-relaunch delegate callback fires
- **THEN** a relaunch-prepared flag is set and the app coordinates its shutdown

### Requirement: Installer Logging

The installer scripts SHALL redirect their output to log files under the daemon log directory with an invocation timestamp.

#### Scenario: Log installer run
- **GIVEN** the installer executes a pre/post-install script
- **WHEN** the script starts
- **THEN** its output is redirected to a log file with a timestamped entry
