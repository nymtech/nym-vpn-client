# Gateway Selection Specification

> Generated by openlore on 2026-06-26
> Source files: `Services/Sources/Services/GatewayManager/*`, `Services/Sources/CountriesManager/GatewayInfoProtocol.swift`, `ServicesMutual/Sources/ConnectionTypes/{GatewayNode,GatewayNodeLocation,GatewayNodeScore,GatewayNodeStore,Country,EntryGateway,ExitRouter,NodeType,GatewayCacheReloadPolicy}.swift`

## Purpose

Discovers, caches, and selects network gateways (entry, exit, VPN nodes) by location, performance score, and protocol availability. Supports country/region selection, fastest-node selection, periodic auto-refresh, and environment-aware caching with a prebundled mainnet fallback.

## Requirements

### Requirement: Gateway Fetching

The system SHALL fetch entry, exit, and VPN gateways from the backend via the gateway worker and cache them in a gateway node store keyed by node type.

#### Scenario: Fetch and store gateways
- **GIVEN** a reload is needed
- **WHEN** the gateway update runs
- **THEN** entry/exit/VPN arrays are fetched from the platform backend and persisted with a last-fetch date

### Requirement: Caching And Persistence

The system SHALL cache gateways in memory and persist them to settings, restoring the prior cache on relaunch.

#### Scenario: Restore cache on relaunch
- **GIVEN** a gateway cache was previously persisted
- **WHEN** the app restarts and loads the gateway store
- **THEN** the prior cache is restored from settings

### Requirement: Cache TTL And Reload

The system SHALL enforce a cache time-to-live and reload when the cache is stale or the environment no longer matches.

#### Scenario: Cache still valid
- **GIVEN** the last fetch was within the TTL window
- **WHEN** the reload check runs
- **THEN** it reports that no reload is needed

#### Scenario: Cache stale
- **GIVEN** the last fetch is older than the TTL
- **WHEN** the reload check runs
- **THEN** it reports that a refresh is required

### Requirement: Environment-Aware Fallback

The system SHALL load prebundled mainnet gateways only when the current environment is mainnet, and SHALL clear the cache on environment change.

#### Scenario: Clear cache on environment change
- **GIVEN** the environment changes away from the cached one
- **WHEN** the environment-change handler runs
- **THEN** the gateway cache is cleared and refetched

### Requirement: Location And Country Aggregation

The system SHALL aggregate gateways by location into a country/region/city hierarchy and present localized, alphabetically sorted country names.

#### Scenario: Build country hierarchy
- **GIVEN** gateways carrying country, region, and city metadata
- **WHEN** countries are derived
- **THEN** a country list with nested regions and sorted cities is produced

#### Scenario: Localize country names
- **GIVEN** a set of country codes
- **WHEN** localization runs
- **THEN** localized country names replace the codes and the list is sorted case-insensitively

### Requirement: Gateway Lookup By Selector

The system SHALL filter gateways matching an entry or exit selector (country, region, gateway ID, or random).

#### Scenario: Filter by country
- **GIVEN** an entry selector for a specific country
- **WHEN** matching gateways are requested
- **THEN** only entry gateways in that country are returned

### Requirement: Fastest Node Selection

The system SHALL select the best gateway by performance score, enabling low-latency routing.

#### Scenario: Pick best-scored gateway
- **GIVEN** a pool of gateways with differing scores
- **WHEN** the best gateway for a selector is requested
- **THEN** the highest-performing matching gateway is returned

### Requirement: Protocol Availability

Each gateway SHALL expose QUIC availability (from its bridge transports) and residential-ASN availability.

#### Scenario: QUIC available
- **GIVEN** a gateway whose bridge transports include QUIC
- **WHEN** its QUIC availability is read
- **THEN** it reports QUIC as available

### Requirement: Automatic Refresh

The system SHALL refresh gateways on a periodic background interval and restart the refresh loop on environment change.

#### Scenario: Periodic refresh
- **GIVEN** the gateway manager is set up
- **WHEN** the auto-update interval elapses
- **THEN** the gateway update repeats until cancelled
