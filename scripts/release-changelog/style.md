# Nym house style — changelog & app-store copy

Distilled from the Nym copywriting style guide (§§1,2,5,6,14) for this pipeline. The author
scripts load this file into their prompts so both the technical changelog and the app-store copy
speak in one consistent voice. Keep it in sync with the master guide.

## Terminology — use these exact forms, consistently, in every entry and every language

- **NymVPN** = the product; **Nym** = the company/project. Never "Nym VPN".
- **Noise Generating Mixnet** — capitalized, no hyphen (never "noise-generating mixnet"); "the Mixnet" once introduced.
- **Mixnet mode** / **dVPN mode** — capitalized product names. NEVER the retired names "Anonymous mode" (→ Mixnet mode) or "Fast mode" (→ dVPN mode).
- **dVPN** (decentralized VPN) · **$NYM token** · **zk-nyms** (zero-knowledge payment tech).
- **metadata** — Nym protects metadata, not just "data".
- **AI-powered surveillance** · **traffic analysis** (not just "tracking") · **censorship-resistant** · **privacy by design** (not "privacy by architecture").
- Keep brand/product names in Latin script in every locale: NymVPN, Nym, Mixnet, dVPN, NYM, zk-nyms, WireGuard, SOCKS5.

## Voice

- Changelog entries: **factual, energetic, scan-friendly.** App-store copy: **benefit-first, concise, confident, direct** — no corporate softness.
- Address the user directly ("you"). Plain and credible; never jargon to impress.

## Precision — don't conflate

- **privacy** = metadata privacy, distinct from content encryption — don't blur them.
- **anonymous** = Nym's strongest claim; reserve it for the mixnet / Mixnet mode, don't apply loosely.
- **secure** = use carefully; Nym's value is anonymity/privacy, not just security.

## Avoid

- Overclaiming: "completely anonymous", "100% private", "unbreakable"; falsifiable superlatives ("fastest", "most secure").
- Corporate buzzwords: leverage, synergy, solutions, best-in-class.
- AI-cliché filler: seamless, game-changer, empower, unlock, delve, "in today's world"; "revolutionary" unless literal.
- Vague fear ("hackers could be watching") without specifics. Passive voice where direct works.

## Word economy

Every word earns its place. Cut hedges (some of, really, very, actually) and filler connectors. Tighter prose is more confident — and it matters most where character budgets are tight (Android ≤500).

## Spelling — American English

-ize not -ise (anonymize, organize) · -or not -our (color, behavior) · -er not -re (center) · no double-l (traveling, labeled).
