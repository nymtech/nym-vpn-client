## Purpose

Integrates the VPN client with Android OS surfaces: foreground/alert notifications, a quick-settings tile, boot-time auto-start, dynamic app shortcuts, and network connectivity monitoring. Lets users control and observe the VPN from system UI and reacts to device-level network changes.

## Requirements

### Requirement: Notification Channel Configuration

The notification service SHALL define a notification channel (name, description, importance) on Android versions that require one.

#### Scenario: Create channel on O+
- **GIVEN** the device runs Android O or later
- **WHEN** notifications are set up
- **THEN** a notification channel is created with description, light color, and vibration

### Requirement: Notification Display

The system SHALL post notifications with a fixed id and content (title, text, content intent to the main activity), optionally with an action, and SHALL clear them by id.

#### Scenario: Show notification with action
- **GIVEN** a notification with an action is requested
- **WHEN** it is displayed
- **THEN** a high-priority notification with the action is posted

### Requirement: Notification Permission Check

The system SHOULD check the notifications runtime permission before posting.

#### Scenario: Skip when denied
- **GIVEN** the notifications permission is denied
- **WHEN** a notification is requested
- **THEN** the post is skipped

### Requirement: Quick Tile State Tracking

The quick-settings tile SHALL track tunnel state by collecting the backend state flow and mapping tunnel state to active/inactive/unavailable tile states.

#### Scenario: Active tile when up
- **GIVEN** the tunnel is up
- **WHEN** the tile updates for the state
- **THEN** the tile is set active and updated

### Requirement: Quick Tile Labeling

The quick-settings tile SHALL display the VPN mode as label and the entry→exit selection as subtitle/state description on supported versions.

#### Scenario: Show mode and route
- **GIVEN** an entry and exit selection
- **WHEN** the tile text is set
- **THEN** the label shows the mode and the subtitle shows the entry→exit route

### Requirement: Quick Tile Toggle

The quick-settings tile SHALL toggle the tunnel on click — starting it when down and stopping it when up.

#### Scenario: Toggle from tile
- **GIVEN** the tunnel is down
- **WHEN** the tile is clicked
- **THEN** the backend starts the tunnel

### Requirement: Boot Auto-Start

The boot receiver SHALL start the tunnel on boot-completed when auto-start is enabled and the tunnel is down.

#### Scenario: Auto-start on boot
- **GIVEN** auto-start is enabled and the tunnel is down
- **WHEN** the device finishes booting
- **THEN** the backend starts the tunnel

#### Scenario: Skip when disabled
- **GIVEN** auto-start is disabled
- **WHEN** the device finishes booting
- **THEN** no tunnel start occurs

### Requirement: Dynamic Shortcut Registration

The shortcut manager SHALL register dynamic shortcuts for start-mixnet, start-WireGuard, and stop actions on supported versions, and SHALL remove them on demand.

#### Scenario: Register shortcuts
- **GIVEN** a supported Android version
- **WHEN** shortcuts are added
- **THEN** start and stop shortcuts are registered with their actions

### Requirement: Network Connectivity Monitoring

The connectivity service SHALL emit connected/disconnected status from a callback flow based on network capabilities and airplane mode, debounced and de-duplicated, with an initial status on subscription.

#### Scenario: Emit connected
- **GIVEN** an active validated network with internet
- **WHEN** the network becomes available
- **THEN** a connected status is emitted

#### Scenario: Emit disconnected on loss
- **GIVEN** no other validated network exists
- **WHEN** the active network is lost
- **THEN** a disconnected status is emitted
