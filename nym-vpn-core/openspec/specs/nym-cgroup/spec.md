# nym-cgroup Specification

> Generated by openlore on 2026-06-26
> Source files: src/lib.rs, src/v1.rs, src/v2.rs

## Purpose

nym-cgroup is a Linux-only abstraction over control groups (cgroups) used to
support split tunneling. It provides handles for both the legacy `net_cls`
controller (cgroup v1) and unified cgroup v2, into which processes can be placed
so their traffic is excluded from the VPN tunnel.

## Requirements

### Requirement: LocateNetClsMount

The crate SHALL locate the `net_cls` cgroup v1 mount point on the host.

#### Scenario: Discover net_cls mount
- **GIVEN** a Linux host that may or may not have a `net_cls` controller mounted
- **WHEN** `find_net_cls_mount()` is called
- **THEN** it returns the mount path if present, or `None` if not mounted

### Requirement: AssignProcessCgroupV1

The crate SHALL open or create a cgroup v1 group and add a process PID to it.

#### Scenario: Add a PID to the exclusion cgroup (v1)
- **GIVEN** a `CGroup1` opened at the exclusions path
- **WHEN** a process PID is added via `add_pid`
- **THEN** the process becomes a member of the `net_cls` exclusion group

### Requirement: AssignProcessCgroupV2

The crate SHALL open the cgroup v2 root and create or open a child group to which
process PIDs can be added.

#### Scenario: Add a PID to the exclusion cgroup (v2)
- **GIVEN** a `CGroup2` root and a created child group named for split-tunnel exclusions
- **WHEN** a process PID is added
- **THEN** the process becomes a member of the v2 exclusion group
