# nym-macos Specification

> Generated by openlore on 2026-06-26
> Source files: src/lib.rs, src/net.rs, src/process.rs

## Purpose

`nym-macos` provides thin, macOS-specific abstractions over low-level system calls that the rest of the VPN client needs but that `std`/portable crates do not expose. It wraps interface IP-alias management (via `ioctl` on a control socket) and process enumeration/path lookup (via the `libproc` family). The entire crate compiles only on `target_os = "macos"`.

## Requirements

### Requirement: InterfaceAliasManagement

The system SHALL add and remove IPv4 and IPv6 address aliases on a named network interface by issuing the appropriate `SIOCAIFADDR`/`SIOCDIFADDR` `ioctl` requests on a datagram control socket of the matching address family.

#### Scenario: AddIpv4Alias
- **GIVEN** an interface name and an `IpAddr::V4` address
- **WHEN** `add_alias` is called
- **THEN** an `AF_INET` datagram control socket is opened, an `ifaliasreq` is populated with the alias address, an unspecified broadcast/destination, and a `255.0.0.0` netmask, and the `siocaifaddr` ioctl is issued

#### Scenario: AddIpv6Alias
- **GIVEN** an interface name and an `IpAddr::V6` address
- **WHEN** `add_alias` is called
- **THEN** an `AF_INET6` datagram control socket is opened, an `in6_aliasreq` is populated with a /64 prefix mask, infinite preferred/valid lifetimes (`u32::MAX`), and the `IN6_IFF_NODAD` flag, and the `siocaifaddr_in6` ioctl is issued

#### Scenario: RemoveAlias
- **GIVEN** an interface name and an address previously aliased
- **WHEN** `remove_alias` is called
- **THEN** the matching `SIOCDIFADDR`/`SIOCDIFADDR_IN6` ioctl is issued on a control socket of the address family, removing the alias

#### Scenario: TruncateLongInterfaceName
- **WHEN** an interface name is copied into a fixed `[c_char; IFNAMSIZ]` request buffer
- **THEN** at most `IFNAMSIZ - 1` bytes are copied and a NUL terminator is appended so the buffer never overflows

### Requirement: ProcessLookupByPath

The system SHALL enumerate all running process identifiers and resolve a PID's executable path, and SHALL return the first PID whose executable path matches a requested path.

#### Scenario: ListAllPids
- **WHEN** `list_pids` is called
- **THEN** `proc_listallpids` is first called with a null buffer to obtain the count, then called again with a correctly sized buffer, returning the vector of PIDs (or an `io::Error` on failure)

#### Scenario: ResolveProcessPath
- **GIVEN** a PID
- **WHEN** `process_path` is called
- **THEN** `proc_pidpath` fills a `MAXPATHLEN` buffer and the result is returned as a `PathBuf`, or an error if the call fails or the bytes are not valid UTF-8

#### Scenario: FindPidByPath
- **GIVEN** a target executable path
- **WHEN** `pid_of_path` is called
- **THEN** the process list is iterated, each PID's path resolved, and the first PID whose path equals the target is returned (or `None` if none match or listing fails)

### Requirement: IPv6NetmaskComputation

The system SHALL compute an IPv6 netmask from a prefix length, clamping prefix lengths greater than or equal to 128 to a fully-set mask.

#### Scenario: PrefixWithinRange
- **WHEN** `ipv6_netmask` is called with a prefix length below 128
- **THEN** the returned mask has the top `prefix_length` bits set

#### Scenario: PrefixAtOrAbove128
- **WHEN** `ipv6_netmask` is called with a prefix length of 128 or greater
- **THEN** the returned mask is `u128::MAX` (all bits set)

## Technical Notes

- **Implementation**: `src/net.rs` (ioctl-based alias management, custom `ifaliasreq`/`in6_aliasreq`/`in6_addrlifetime` `#[repr(C)]` structs), `src/process.rs` (libproc-based PID enumeration), `src/lib.rs` (module gate `#![cfg(target_os = "macos")]`).
- **Dependencies**: `nix` (libc bindings, `ioctl_write_ptr!` macros, socket helpers), `tracing` (error logging), `tokio`. Code is derived from Mullvad VPN's macOS helpers. In the workspace it supplies macOS platform primitives consumed by the tunnel/firewall/networking layers; `add_alias`/`remove_alias` model the behavior of the `ifconfig` tool.
