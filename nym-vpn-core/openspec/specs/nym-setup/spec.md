# nym-setup Specification

> Generated by openlore on 2026-06-26
> Source files: src/main.rs, src/macos.rs, src/service_binary.rs

## Purpose

nym-setup is a small command-line helper binary that performs daemon
installation/setup tasks. It exposes subcommands to prepare the daemon for restart
and to install the daemon as a system service, resolving the service binary path
as part of the process.

## Requirements

### Requirement: SetupSubcommands

The binary SHALL expose subcommands for daemon lifecycle setup tasks, including
preparing a restart and installing the service.

#### Scenario: Install the daemon service
- **GIVEN** a privileged invocation of nym-setup
- **WHEN** the `InstallService` subcommand is run
- **THEN** the daemon is registered as a system service

#### Scenario: Prepare for restart
- **GIVEN** the daemon needs to be restarted
- **WHEN** the `PrepareRestart` subcommand is run
- **THEN** the setup steps required before restarting the daemon are performed

### Requirement: ResolveServiceBinaryPath

The binary SHALL resolve the filesystem path of the service binary to install.

#### Scenario: Locate service binary
- **GIVEN** the setup binary is running
- **WHEN** it needs to register the service
- **THEN** `service_binary_path()` returns the path to the daemon executable

## Technical Notes

- **Implementation**: `src/main.rs` (`Command` subcommands via clap), `src/service_binary.rs` (`service_binary_path`), `src/macos.rs`
- **Dependencies**: clap, anyhow; installation helper for `nym-vpnd`
