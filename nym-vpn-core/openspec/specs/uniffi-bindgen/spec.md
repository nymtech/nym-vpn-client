## Purpose

This crate is a minimal binary wrapper that exposes the UniFFI code-generation CLI as a project-local executable. It exists so the workspace can pin and invoke the exact `uniffi` version it depends on when generating Swift/Kotlin foreign-language bindings from the FFI crates, rather than relying on a globally installed `uniffi-bindgen`.

## Requirements

### Requirement: BindgenCliEntrypoint

The system MUST provide an executable that delegates entirely to UniFFI's built-in bindgen CLI driver, enabled via the `uniffi` `cli` feature.

#### Scenario: Running the bindgen binary
- **GIVEN** the crate is built with `uniffi` compiled with the `cli` feature
- **WHEN** the `uniffi-bindgen` binary is executed with bindgen arguments
- **THEN** `main` calls `uniffi::uniffi_bindgen_main()`, which parses the arguments and runs the binding-generation workflow

## Technical Notes

- **Implementation**: `src/main.rs` (`fn main()` calling `uniffi::uniffi_bindgen_main()`).
- **Dependencies**: Only `uniffi` with the `cli` feature. In the workspace this binary is the codegen tool used to produce foreign-language bindings for `nym-vpn-lib-uniffi` and `nym-vpn-rpc-uniffi`, ensuring the generator version matches the `uniffi` runtime those crates link against.
