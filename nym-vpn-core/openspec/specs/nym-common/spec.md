# nym-common Specification

> Generated by openlore on 2026-06-26
> Source files: src/lib.rs, src/error.rs, src/flood.rs

## Purpose

nym-common is a small shared utility crate providing cross-cutting helpers used by
other nym-vpn-core crates. It exposes a common error type and a "flood detection"
utility for spotting code paths that execute unusually frequently (a guard against
busy loops / runaway callbacks).

## Requirements

### Requirement: SharedErrorType

The crate SHALL provide a reusable error type re-exported at the crate root for
use across consuming crates.

#### Scenario: Consumer reports an error
- **GIVEN** a crate depends on nym-common
- **WHEN** it needs a common error representation
- **THEN** it uses the error type re-exported from `nym-common`

### Requirement: FloodDetection

The crate SHALL detect when a code location is hit more than a threshold number of
times within a fixed time interval, so callers can log runaway execution.

#### Scenario: Code runs too frequently
- **GIVEN** a `DetectFlood` instance with a calls threshold and interval
- **WHEN** `bump()` is called more than the threshold within the interval
- **THEN** it returns true to signal the location is being hit unusually frequently

## Technical Notes

- **Implementation**: `src/flood.rs` (`DetectFlood`, `bump()`), `src/error.rs`
- **Dependencies**: thiserror/anyhow; consumed broadly across nym-vpn-core crates as a low-level utility (bottom of the dependency layering)
