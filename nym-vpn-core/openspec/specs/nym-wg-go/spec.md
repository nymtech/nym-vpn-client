# nym-wg-go Specification

> Generated by openlore on 2026-06-26
> Source files: src/lib.rs, src/wireguard_go.rs, src/netstack.rs, src/amnezia.rs, src/uapi.rs

## Purpose

nym-wg-go is the Rust bridge to the (amnezia)wireguard-go library, used to create
and drive WireGuard tunnels. It supports both a real OS tun-device tunnel and a
userspace netstack tunnel (for in-tunnel connection proxies), configures peers via
the WireGuard UAPI, exposes per-peer statistics, and optionally enables Amnezia
obfuscation features.

## Requirements

### Requirement: StartWireguardTunnel

The crate SHALL start a WireGuard tunnel from an interface and peer configuration.

#### Scenario: Bring up a tunnel
- **GIVEN** a `Config` with interface keys and peer endpoints
- **WHEN** `Tunnel::start(...)` is called
- **THEN** a running WireGuard tunnel handle is returned (or an error if startup fails)

### Requirement: UpdatePeersAtRuntime

The crate SHALL update peer endpoints on a running tunnel without restarting it.

#### Scenario: Roam to a new endpoint
- **GIVEN** a running tunnel
- **WHEN** `update_peers(...)` is called with new peer endpoint updates
- **THEN** the tunnel reconfigures its peers via the UAPI

### Requirement: NetstackInTunnelProxies

The crate SHALL provide userspace netstack tunnels that expose in-tunnel UDP and
TCP connection proxies.

#### Scenario: Open an in-tunnel UDP proxy
- **GIVEN** a netstack `Tunnel`
- **WHEN** `start_in_tunnel_udp_connection_proxy(...)` is called
- **THEN** an `InTunnelUdpConnectionProxy` is returned with a local listen address that forwards through the tunnel

### Requirement: ExposeTunnelStatistics

The crate SHALL expose per-peer handshake and traffic statistics for a running
tunnel.

#### Scenario: Read connection stats
- **GIVEN** a running tunnel with a `TunnelStatsReader`
- **WHEN** `get_stats()` is called
- **THEN** it reports per-peer stats including whether handshakes completed and whether all peers are connected

### Requirement: OptionalAmneziaObfuscation

The crate SHALL allow optional Amnezia obfuscation parameters to be applied to the
tunnel configuration.

#### Scenario: Enable obfuscation
- **GIVEN** an `AmneziaConfig`
- **WHEN** it is appended to the UAPI config and validated
- **THEN** the tunnel is configured with the obfuscation parameters when valid

### Requirement: StopTunnel

The crate SHALL cleanly stop a running tunnel and release its resources.

#### Scenario: Tear down a tunnel
- **GIVEN** a running tunnel
- **WHEN** `stop()` is called
- **THEN** the underlying wireguard-go instance is shut down and sockets are released

## Technical Notes

- **Implementation**: `src/wireguard_go.rs` (`Tunnel`, `Config`, `update_peers`, `TunnelStatsReader`), `src/netstack.rs` (in-tunnel proxies), `src/amnezia.rs` (`AmneziaConfig`), `src/uapi.rs` (`UapiConfigBuilder`)
- **Dependencies**: FFI/cgo to (amnezia)wireguard-go (libwg); consumed by `nym-vpn-lib` for the WireGuard/dVPN data path
