## Purpose

nym-socks5-proxy is a standalone SOCKS5 proxy subprocess managed by the `nym-vpnd`
daemon. It accepts SOCKS5 client connections and decides, per destination, whether
to route traffic through the VPN tunnel or out the default (non-tunnel) interface
based on configurable country/domain/IP exclusion rules, monitoring the host's
default interface for changes.

## Requirements

### Requirement: RunSocks5Proxy

The binary SHALL run a SOCKS5 proxy that serves client connections until shut down.

#### Scenario: Serve SOCKS5 clients
- **GIVEN** a validated proxy configuration
- **WHEN** `run(...)` is invoked
- **THEN** the proxy listens for SOCKS5 connections and proxies them according to its routing decisions

### Requirement: SplitRoutingDecisions

The proxy SHALL decide whether each destination is excluded from the tunnel based
on excluded countries (by domain and by IP geolocation).

#### Scenario: Exclude a destination
- **GIVEN** a routing database loaded with excluded countries
- **WHEN** a connection targets a host/IP in an excluded country
- **THEN** `decide_route_for_addrs` returns a routing decision sending it out the default interface rather than the tunnel

### Requirement: DefaultInterfaceMonitoring

The proxy SHALL monitor the host's default network interface and bind
non-tunnel traffic to it, per platform.

#### Scenario: Default interface changes
- **GIVEN** a running default-interface monitor
- **WHEN** the host's default interface changes
- **THEN** the watch channel updates and subsequent excluded connections bind to the new default interface

### Requirement: GeoIpAndDomainDatabases

The proxy SHALL load GeoIP and domain databases (managed via a file manager) to
support exclusion decisions.

#### Scenario: Load exclusion data
- **GIVEN** a data directory containing the GeoIP/domain datasets
- **WHEN** the routing database is loaded
- **THEN** domain and IP exclusion lookups (`is_excluded_domain`, `GeoIpDatabase::is_excluded`) are available
