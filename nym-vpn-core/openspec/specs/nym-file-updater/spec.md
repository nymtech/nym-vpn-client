# nym-file-updater Specification

> Generated by openlore on 2026-06-26
> Source files: src/lib.rs, src/updater.rs, src/download.rs, src/error.rs

## Purpose

nym-file-updater is a background service that downloads and updates files on
demand. It runs as an async task driven by a handle, accepting registration and
update requests, performing HTTP downloads, and reporting an update outcome.

## Requirements

### Requirement: BackgroundUpdaterTask

The crate SHALL run as a cancellable background task driven through a handle.

#### Scenario: Run and cancel the updater
- **GIVEN** a `FileUpdater` and its `FileUpdaterHandle` created via `new()`
- **WHEN** `run(cancel_token)` is spawned and the token is later cancelled
- **THEN** the updater processes requests until cancellation and then stops

### Requirement: RequestFileUpdate

The crate SHALL accept update requests through the handle and return an outcome.

#### Scenario: Request an update
- **GIVEN** a registered file/target
- **WHEN** `request_update(...)` is called on the handle
- **THEN** the updater downloads the file and returns an `UpdateOutcome` (or a `FileUpdaterError`)

### Requirement: RegisterUpdateTargets

The crate SHALL allow callers to register the files/targets it manages.

#### Scenario: Register a target
- **GIVEN** an updater handle
- **WHEN** `register(...)` is called
- **THEN** the target becomes known to the updater for subsequent update requests

## Technical Notes

- **Implementation**: `src/updater.rs` (`FileUpdater`, `FileUpdaterHandle`, `run`, `request_update`, `register`), `src/download.rs`, `src/error.rs` (`FileUpdaterError`, `UpdateOutcome`)
- **Dependencies**: reqwest, tokio, tokio-util (CancellationToken); used by `nym-vpn-lib` for file/asset updates
