# nym-exclude Specification

> Generated by openlore on 2026-06-26
> Source files: src/main.rs, src/linux.rs

## Purpose

nym-exclude is a small Linux-only binary that launches a program whose network
traffic is excluded from the Nym VPN tunnel. It places the spawned process into
the split-tunnel cgroup (v2 when available, falling back to / additionally adding
the legacy v1 `net_cls` group) before executing the target program.

## Requirements

### Requirement: LaunchProgramOutsideTunnel

The binary SHALL launch a user-specified program in a cgroup whose traffic is
excluded from the VPN tunnel.

#### Scenario: Run a command outside the tunnel
- **GIVEN** a Linux host with the split-tunnel cgroup available
- **WHEN** a user runs `nym-exclude <program>`
- **THEN** the current process is added to the exclusion cgroup and the target program is exec'd within it

### Requirement: CgroupV2WithV1Fallback

The binary SHALL add the process to the cgroup v2 exclusion group when built with
cgroup2 support, and SHALL also attempt to add it to the legacy v1 `net_cls` group
when present.

#### Scenario: Dual cgroup membership
- **GIVEN** a host where both cgroup v2 and a v1 `net_cls` mount exist
- **WHEN** the process is excluded
- **THEN** it is added to the v2 exclusion group and, if the v1 mount exists, also to the v1 group

## Technical Notes

- **Implementation**: `src/linux.rs` (`exclude`, `add_to_cgroups_v1_if_exists`, `run`), `src/main.rs`
- **Dependencies**: `nym-cgroup`, nix; standalone helper binary supporting Linux split tunneling
