## Purpose

nym-apple-network is a minimal Rust wrapper around Apple's Network.framework
(`nw_*` C APIs). It primarily exposes a path monitor for observing network
reachability and interface changes on Apple platforms, along with typed wrappers
for paths, interfaces, and endpoints, and a retain/release smart pointer for
Objective-C objects.

## Requirements

### Requirement: NetworkPathMonitoring

The crate SHALL provide a path monitor that reports network path updates via a
caller-supplied handler.

#### Scenario: Observe path changes
- **GIVEN** a `PathMonitor` with an update handler and dispatch queue set
- **WHEN** `start()` is called and the network path changes
- **THEN** the update handler is invoked with the new `Path`

### Requirement: InterfaceConstraints

The crate SHALL allow the monitor to require or prohibit specific interface types.

#### Scenario: Restrict to a required interface
- **GIVEN** a `PathMonitor` created with `new_with_required_interface(...)` or configured via `prohibit_interface_type(...)`
- **WHEN** it monitors the path
- **THEN** path updates reflect the required/prohibited interface constraints

### Requirement: InspectPathProperties

The crate SHALL expose path properties such as status, available interfaces,
gateways, and IPv4/IPv6/DNS support.

#### Scenario: Query path capabilities
- **GIVEN** a `Path` from a monitor update
- **WHEN** its accessors are called (`status`, `available_interfaces`, `supports_ipv4`, `is_expensive`, etc.)
- **THEN** it returns the corresponding network path attributes

### Requirement: SafeObjectLifetime

The crate SHALL manage Network.framework object lifetimes safely via retain/release.

#### Scenario: Retained object cleanup
- **GIVEN** a `Retained<T>` wrapping an `nw_object`
- **WHEN** it is dropped
- **THEN** the underlying object is released exactly once
